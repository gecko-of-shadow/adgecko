Gecko Adblock settings

Everything

The Twitch ad-free stream swap and the uBlock Origin YouTube scriptlets are always on while the extension is enabled: they are vendored, unmodified code that this extension cannot switch off without extra permissions. To stop them, turn the extension off in chrome://extensions. A site's own switch in the popup turns off this extension's other helpers on that site.

Features

"Live" switches apply at once. Switches for page scripts (YouTube, Kick) apply to the next action the script takes; nothing already running is undone and no tab is reloaded for you.

Threat feed and lists

Revert lists drops every downloaded list and goes back to the lists packed with this version.

Allow this domain

A domain added here (and its subdomains) is never blocked: not by the malware lists and not by the filter lists. Use it when Chrome shows a blocked page ("blocked by an extension") for a site you trust: add its domain here, then reload the page. "Allow this site" in the popup cannot help there, because the blocked page is not a site the popup can see. Add only sites you trust.
