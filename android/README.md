# Adgecko Shield (Android)

This folder holds the Android app "Adgecko Shield": a local DNS-only VPN filter for all apps, with data from `src/rules/` at build time. Read `docs/android/shield.md` for the build, the install and the checks, and `docs/android/PLAN.md` for the plan. All phone behaviour is UNVERIFIED until a run on the owner's phone proves it.
